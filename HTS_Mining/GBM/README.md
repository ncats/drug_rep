# NCATS GBM Primary High-Throughput Screening Dataset

## Overview

Primary high-throughput screening results from three NCATS compound libraries: the NCATS Pharmaceutical Collection (NPC), NPACT, and the Library of Pharmacologically Active Compounds (LOPAC), evaluated across four glioblastoma-related cell models: A172, H4, T98G, and U251.

## Data organization

The dataset is provided as 12 CSV files, with one file for each combination of compound library and cell model.

## Contents

Each file contains the primary screening measurements and source fields from the corresponding screening record. The original protocol name is retained where available.

## Files

12 library-by-cell-line CSV files are provided under `data/`.

A data dictionary and source/QC information are provided under `metadata/`.
